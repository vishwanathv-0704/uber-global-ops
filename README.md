# Uber Global Operations Assistant

Agentic AI system for airport operational analysis and decision support.

## Features

- Airport operational analysis
- Multi-agent workflow
- RAG-based policy retrieval
- Operational recommendations
- Policy compliance checks
- Risk classification and human approval
- Guardrails and error handling
- Audit-ready outputs
- Streamlit dashboard

## Tech Stack

- Python
- Streamlit
- Ollama / Local LLM
- FAISS
- Sentence Transformers
- Pandas

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
